## Overview

Kaivo pairs a granular sample engine with a physical resonator model, running audio grains through plucked strings, struck plates, and air column resonators for organic hybrid timbres.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Madrona Labs Kaivo** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Granular Source** | Configurable grain engine with sample, position, size, and scatter |
| **Physical Resonator** | String, membrane, plate, and bar resonator physical models |
| **Body Filter** | Acoustic body resonance model adding real instrument color |
| **MPE Support** | Full MIDI Polyphonic Expression support for per-note modulation |
